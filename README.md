## 🤔 어떤 사이트인가요?

공모전 공고는 위비티, 콘테스트코리아, 씽굿 같은 여러 사이트에 **나뉘어** 올라오고, 같은 공모전이 여러 곳에 조금씩 다른 제목으로 실리기도 합니다.
공모모아는 이 사이트들의 공개 목록을 **하루 두 번 자동으로 모아**, 같은 공모전은 한 줄로 합치고 마감이 가까운 순서로 보여 줍니다.

| 구분 | 무엇을 하나 |
|---|---|
| 🧺 **모으기** | 출처 세 곳의 공개 목록을 모아 제목·주최·분야·참가 대상·상금·마감일을 같은 모양으로 정리 |
| 🔗 **합치기** | 마감일이 같고 제목이 거의 같으면 같은 공모전으로 보고 한 줄로 합침 |
| 🔎 **원문 확인** | 공고 원문을 열어 보고, 원문에 마감이 확실히 적혀 있을 때만 '마감'으로 바꿈 |

## 🎯 내 조건과 관심 공모전

- 🙋 **내 조건**: 신분(초중고생·대학생·대학원생·직장인·일반인), 출생연도, 지역, 관심 분야를 넣으면 참가 대상·지역·나이 조건이 맞지 않는 공모전을 가려 줍니다.
- ⭐ **관심 담기**: 마음에 드는 공모전을 모아 두고, 준비 중 · 제출 완료 · 수상 · 탈락으로 진행 상황을 적어 둘 수 있습니다.
- 🔠 **글자 크게**: 위쪽 '가＋' 단추로 모든 글자를 키울 수 있습니다.

모두 **지금 쓰는 브라우저 안에만** 저장됩니다.

## 🔒 개인정보는 어떻게 다루나요?

- 🙅 **가입·로그인이 없고**, 이름·연락처 같은 개인정보를 받지 않습니다.
- 📱 내 조건 · 관심 공모전 · 진행 상황 · 글자 크기는 **지금 쓰는 브라우저 안에만** 저장되고 서버로 보내지 않습니다.
- 🍪 쿠키나 방문 분석 도구를 쓰지 않습니다.
- 🛡️ 보안 헤더(HTTPS 고정·콘텐츠 보안 정책 등)로 이 사이트 밖의 스크립트는 실행되지 않게 막습니다.
- 🧹 브라우저의 사이트 데이터를 지우면 저장된 내용도 모두 사라집니다.

## 🛠️ 직접 실행해 보기 (개발자용)

<details>
<summary><b>펼쳐 보기</b> — 폴더 구성, 실행 방법, 테스트</summary>

### 📁 폴더 구성

```text
collector/        출처 수집 → 정리·합치기 → 화면용 자료 생성 (Python 표준 라이브러리만 사용)
  sources/        출처별 목록 읽기
site/             정적 웹 화면 (HTML·CSS·JS, 빌드 도구 없음)
deploy/           서버 운영: 한 바퀴 갱신, 원문 확인, 게시
tests/            수집·합치기·정리 규칙 테스트
```

### ▶️ 실행

Python 3.9 이상이면 됩니다.

```bash
python3 -m collector.collect     # 출처 수집 → data/raw/
python3 -m collector.build       # 정리·합치기 → site/data/
python3 -m http.server 8765 --directory site   # http://127.0.0.1:8765
```

`data/`와 `site/data/`는 저장소에 넣지 않습니다. 위 순서로 다시 만듭니다.

### ✅ 테스트

```bash
python3 -m unittest discover -s tests -t .
```

### ⏰ 운영

- 서버에서는 `deploy/vps_cycle.sh full`(하루 두 번)과 `quick`(매시)이 수집·빌드·원문 확인·게시를 차례로 돌립니다.
  운영 폴더는 이 저장소의 한 단계 위(`repo/` 옆의 `state/`·`public/`)이고, `GONGMO_ROOT`로 바꿀 수 있습니다.
- 공개 전에 걸러 낼 운영자 개인 맥락 낱말은 저장소에 넣지 않고 `private/privacy-patterns.txt`(`.gitignore`)에서 읽습니다.
  형식은 `tests/fixtures/operator-example/privacy-patterns.txt`의 예시와 같습니다.

</details>
